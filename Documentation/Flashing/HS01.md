# Flashing the FNIRSI HS-01

The HS-01 (also sold as the KAIWEETS KETS02) is flashed through the WCH ROM bootloader built into the CH571 MCU, using [wchisp](https://github.com/ch32-rs/wchisp).
The ROM bootloader cannot be erased, so a failed flash can always be retried.

## Steps

1. Install `wchisp` (a release binary from its GitHub page, or `cargo install wchisp`).
2. Unplug the iron. Hold the **right** button and plug in the USB-C cable to the computer.
3. The bootloader only stays active for about 7-8 seconds, so start the flash straight away:

```sh
wchisp flash HS01_EN.bin
```

To avoid racing the timeout, start this loop first and then plug the iron in:

```sh
until wchisp info >/dev/null 2>&1; do sleep 0.4; done; wchisp flash HS01_EN.bin
```

4. When `wchisp` reports the verify passed, unplug and replug the iron.

On Linux you may need a udev rule for the bootloader (USB ID `4348:55e0` / `1a86:55e0`), or to run `wchisp` with `sudo`.

## Notes

- Flashing IronOS replaces the vendor's own updater (the left-button bootloader). The vendor's firmware update tool will no longer work afterwards.
- The vendor firmware has read-out protection enabled, so it cannot be backed up from the iron.
- IronOS cannot tell how much current the charger can supply. On a charger weaker than 65 W, set a power limit in the power settings.
